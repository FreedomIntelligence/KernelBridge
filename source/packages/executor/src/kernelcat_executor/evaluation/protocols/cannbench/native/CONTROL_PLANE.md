# 原生算子评测控制面

本组件管理原生算子的环境、候选、构建、实验和评测凭据。应用通过配置的业务工具调用有限命令；通用任务入口使用 Pi SDK 和 LoopX。

## 对象与身份

| 对象 | 内容 |
| --- | --- |
| EnvironmentFingerprint | SoC、CANN、工具链和测试集摘要 |
| ParentSet | 源码父版本、性能比较父版本和可选组合载体 |
| Policy | 优化假设、适用输入、回退实现和预期诊断特征 |
| Candidate | 冻结源码、父版本、任务、输入和环境身份 |
| BuildIdentity | 源码、任务、环境与编译选项 |
| ExperimentPlan | 设备、输入、重复次数、指标和随机种子 |
| EvidenceRecord | 执行状态、原始产物、来源与关联摘要 |
| GateReceipt | 正确性、测量和任务条件的验证结果 |

## 存储与执行

CAS 按 SHA256 保存源码、标准输出、错误输出、测量样本和结构化凭据。SQLite ledger 记录实体、事件、运行状态、资源 lease 和产物索引。实验使用幂等请求身份，恢复时读取原执行状态与终态产物。

同一实验的计时与 profiler 可复用已冻结的构建产物。Event 计时负责性能比较，PMU 和 IR 用于分析执行特征；各类输出分别绑定源码、构建、设备和测试输入。

## 命令入口

在本目录运行帮助以查看命令和参数：

```sh
python3 kcatctl.py --help
```

典型操作包括初始化状态、检查环境、冻结源码、创建优化假设、导入评测证据以及验证候选。实际设备调用由部署配置的适配器执行。

## 结果读取

CLI 返回 JSON，包含状态、检查结果、内容身份和原始产物引用。按 candidate、experiment、build、casepack 关联源码与结果。执行超时或响应中断时，使用原请求身份查询终态并收集已产生的日志。
